# Project Documents

This folder contains project rules, coding standards, and database design notes.

## Files

| File | Purpose |
| --- | --- |
| `PROJECT_RULES.md` | Project-wide rules that should be followed everywhere. |
| `CODING_STANDARDS.md` | Shared coding standards for frontend and backend. |
| `FRONTEND_BEST_PRACTICES.md` | Frontend-specific standards, including form and validation rules. |
| `BACKEND_BEST_PRACTICES.md` | Backend-specific standards for APIs, Prisma, database, and transactions. |
| `DATABASE_DESIGN_RULES.md` | Database naming, audit, transaction, Prisma, and reporting rules. |
| `INVENTORY_TABLES.md` | Inventory table names and simple descriptions. |
| `INVENTORY_SCHEMA.md` | Inventory tables, fields, and plain-English field descriptions. |
| `BANK_DEPOSIT_SCHEMA.md` | Bank account and bank deposit voucher tables with plain-English field descriptions. |

## Important Naming Rule

Keep labels, field names, descriptions, table names, and titles easy to understand for non-native speakers and less technical staff.
