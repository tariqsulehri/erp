## 4. How to Run a New Audit

To run a fresh automated audit using the kit:
1. Open your AI agent or terminal in `/Users/tk-lpt-1088/development/react/erp/ERP`.
2. Select a prompt from [`audit/PROMPTS.md`](/Users/tk-lpt-1088/development/react/erp/ERP/audit/PROMPTS.md) (e.g. Prompt 2 for Standard Full Audit or Prompt 13 to verify existing findings).
3. The kit will execute scanners, evaluate domain rules in [`audit/project-standards.md`](/Users/tk-lpt-1088/development/react/erp/ERP/audit/project-standards.md), and write the report to `audit/results/<date>_<name>/report.html`.
